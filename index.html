DRAWING REGISTER FAQ

Questions before you export

The practical details about compatibility, revisions, presets and licensing.

Which Revit versions are supported?
Drawing Register Exporter supports Autodesk Revit 2024, 2025, 2026 and 2027 on Windows 64-bit.
How are sheet numbers and document numbers created?
Choose the Revit parameters in the required order and set a separator after each segment. Version 4.1 can also create a separate composite drawing or document-number column from project and sheet parameters, which suits ISO 19650-style conventions.
How does the revision history work?
The plugin reads revision dates across the project, creates the matching date columns, and places each sheet’s revision code—such as P01, C01 or C02—under the correct issue date. You can change the display format, split dates into Day / Month / Year rows and choose the source order for ambiguous six-digit dates.
Can I exclude sheets or hide sheets that were never issued?
Yes. Exclude sheets by checkbox, include/exclude rule, parameter value or manually entered sheet number. A live panel shows which sheets will not export and why. You can also hide excluded sheets from the preview and remove never-issued sheets from both preview and export.
What can Custom Revision Rows contain?
They can contain free text, checkboxes, values read from Revit revision parameters, or section headings. Rows can be placed above or below the sheet list. Values are stored with the project and backed by project-specific local recovery.
Do presets survive an upgrade?
Yes. Existing presets remain compatible with version 4.1; new settings use safe defaults. You can save named presets, update them, and import or export preset files for other project types.
What does the 30-day trial include?
The Autodesk App Store provides a free 30-day trial of the plugin. The interactive website demo uses representative browser data, requires no Revit installation and does not touch your project.

MIDP SHEET CREATOR FAQ

Know before you create

Workbook requirements, mapping rules, entitlement and support information from the Autodesk Marketplace listing.

Which Revit versions and spreadsheet formats are supported?
MIDP Sheet Creator supports Autodesk Revit 2024, 2025, 2026 and 2027 on Windows 64-bit. Source files must be Microsoft Excel .xlsx workbooks.
What if my workbook has notes above the MIDP table?
Set how many leading rows to ignore, then identify the row containing the Excel parameter names. Empty rows can be removed automatically. The workbook must contain a clearly identifiable parameter-name row.
How are Excel columns mapped to Revit?
Map each Excel column name to a compatible Revit sheet parameter and assign the Sheet Name source. Any custom Revit parameter must already exist and be available on sheets before the plugin can populate it.
What happens to dashes in sheet numbers?
The Marketplace version removes dashes from values used as Revit sheet numbers. If the project standard needs fixed separators, place those separators in the title block family. The live demo also shows the current one-cell and multi-cell number-mapping workflows.
How are existing sheets, duplicates and unwanted rows handled?
You can skip sheet numbers that already exist in the Revit project, ignore duplicate spreadsheet numbers while keeping the first valid occurrence, and manually exclude individual rows with preview checkboxes. Live totals show exactly how many sheets will be created or skipped.
What is stored in a preset?
Presets are stored locally and contain reusable mappings and configuration options. Spreadsheet content is not included, so loading a preset does not carry MIDP project data into the next workbook.
Why must I be signed in to Autodesk?
An active Autodesk Marketplace trial or subscription is required. You must be signed in to your Autodesk account inside Revit so the plugin can verify entitlement. Internet access is needed for initial and periodic verification.
What should I include in a support request?
Include your Revit version, MIDP Sheet Creator version, Windows version, the workflow and error description, and a screenshot of the message or unexpected result. If relevant, attach a sample workbook with confidential information removed.
